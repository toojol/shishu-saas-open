# 应付、毛利与日结对账

实现位于 `saas-finance`。

## 应付到期

- 到期日 = 业务日 + 账期天数；账期为空或负数按现结（0 天）处理。
- `asOf ≥ 到期日` 即视为到期或超期。

## 应付状态

| 状态 | 条件 |
|------|------|
| `OPEN` | 已付为 0 |
| `PARTIAL` | 已付不为 0，且剩余不为 0 |
| `CLOSED` | 剩余为 0 |
| `VOID` | 作废（由调用方标记） |

退供产生的负数应付同样适用：剩余与已付都为负，已付向应付靠拢。

## 核销范围

一次核销额必须落在剩余应付范围内：

- 正数应付：0 < 核销额 ≤ 剩余；
- 负数应付：剩余 ≤ 核销额 < 0；
- 剩余为 0 时，任何核销都不合法。

对应代码：`FinPayableMath.allocWithinRemaining`。

## 毛利率

毛利率 = 毛利 × 100 / 净销售，保留两位小数（HALF_UP）。净销售为 0 时返回空，避免除零。

## 日结对账

日结按支付方式拆分汇总，并与应收销售额比对：

- 支付方式：现金、微信、支付宝、储值、其它；
- 退款按负数计入对应方式；
- 合计与销售额的差额即"未匹配"，不为 0 时需要人工核查；
- 现金单独计算长短款：实点现金 − 应有现金。正数为长款，负数为短款。

对应代码：`DayCloseReconcile.summarize` 与 `DayCloseReconcile.cashDiff`。
